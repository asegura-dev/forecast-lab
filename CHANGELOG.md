# Changelog

Notable changes to **forecast-lab**, newest first. This is a research lab rather than a released product, so entries are **dated** instead of versioned. It complements - it does not replace - the [STATUS logs](docs/status/) (what an experiment measured), the [ADRs](docs/adr/) (decisions and their reasoning), and the git history. Only notable changes are listed here; `git log` has every commit. The format loosely follows [Keep a Changelog](https://keepachangelog.com).

## 2026-08-18 - The data source is measured before it is adopted, and the foundations are built

### Added

- **[STATUS 2026-08-18](docs/status/STATUS-2026-08-dukascopy-probe.md)** - a probe run before adopting any data source, answering five questions that were open: whether each of the twelve symbols exists, its coverage and density, how far back hourly history reaches, what anchor the bars use, and whether the venue quotes the same instrument as the reference exports. **Verdict: GO.** 457 of 457 hourly timestamps matched, with a return correlation of **0.9996** - the same instrument, not a lookalike. Two side findings changed the project: the comparison yielded a **measured spread of ~1.6 bps**, which replaces the assumed transaction cost in the break-even calculation, and the feed carries a **volume** column the reference exports lack, re-opening a family of indicators that had been out of reach.
- **[ADR-002](docs/adr/ADR-002-data-source-and-symbol-set.md)** - the data source and the symbol set, decided on the probe's evidence. Dukascopy because it is fetchable with no API key (so anyone who clones the repository can reproduce every number), extends forward (so a genuinely unseen holdout can exist at all), and can be hashed for provenance. The prior project's exports are kept in a separate directory and read exactly once, to reproduce its published baseline. Each `(symbol, timeframe)` is fetched independently rather than resampled, because a venue's higher-timeframe bars are anchored to its own trading day and that anchor moves with daylight saving time.
- **Contracts, the layering guard and the `symbols` command** - the first working slice. `Timeframe` knows its own duration; `SymbolSpec` refuses anything that would not survive as a file name on a case-insensitive filesystem; `SeriesMeta` rejects naive timestamps and carries grid anchors as a **set**, because a series whose trading day shifts with daylight saving legitimately has two. Series discovery reads file names only - the cheap question kept apart from the expensive one - via a configurable named-group regex rather than a positional split, so `BINANCE_BTC_USDT_1H.csv` cannot be misread as the symbol `USDT`. The scan is non-recursive on purpose and reports every file it ignored, because a scan that quietly skips half a directory is how somebody models a subset they did not choose.
- **[README](README.md)** and **[docs/INDEX.md](docs/INDEX.md)** - the front door and the one-line-per-file reference.

### Changed

- **VIX is dropped from the symbol set**, and the modelling window becomes 2018-01 onward. Its hourly history begins only in 2022-10, and it was the binding constraint on the whole set: keeping it costs **28,136 bars, 55% of the available sample**, to buy a feature whose measured correlation with the target is **-0.011**. The larger window lowers the minimum detectable effect - the smallest edge the design can tell apart from luck - from 52.12% to **51.42%** on a single split, which matters because the break-even accuracy sits at 51.92%. Realised volatility, computed causally from the target and the S&P, takes its place: it tracks the *level* of the fear regime at +0.75 against VIX, though not its *changes*, which is expected since one is forward-looking implied volatility and the other its backward-looking twin. The decision rests on an asymmetry rather than on proof - the cost is certain, the benefit is not - and the ADR says so.

### Fixed

- **The CLI collapsed into a bare command.** A Typer application holding a single command treats it as the root, so `forecast-lab symbols` failed with "unexpected extra argument". Fixed with an explicit callback, and the reason is recorded in the code so it does not get removed as redundant. The 52 tests all passed while this was broken - which is the argument for running the thing, not only testing it.
- **The command's help output was unreadable**, because Rich re-wraps a docstring and a long one came out shredded. Command docstrings are now a single line, with the reasoning in comments.

## 2026-08-17 - The architecture is decided, and what is deliberately not built is recorded

### Added

- **[ADR-001](docs/adr/ADR-001-hexagonal-architecture.md)** - four layers (`contracts`, `ingest`, `research`, `interfaces`) with dependencies pointing inward. The load-bearing rule is that **`research` may never reach for data**: it receives frames and cannot open a file or call an API, because a layer that can quietly re-read the world produces experiments that cannot be reproduced from stored inputs, and a result that cannot be reproduced cannot be falsified. The ADR also records what is deliberately *not* built - no ports package, no storage layer - on the grounds that an abstract interface earns its place when a second implementation exists, and today there is exactly one source feeding one caller. It closes two holes in the dependency guard along the way: relative imports of the form `from .. import x` are invisible to the obvious implementation, and a module sitting at the package root is neither attributed to a layer nor checkable against one, which is precisely where a leak would hide.
- **[Engineering conventions](docs/guides/engineering-conventions.md)** - the three gates, the hard architectural rules, the data rules that exist because breaking them once produced a wrong number that looked right, and where each kind of document lives.
- Project scaffolding: `pyproject.toml` with the three gates configured (`ruff`, `mypy --strict`, `pytest` with hermetic defaults and network tests opt-in), `.gitignore`, `.gitattributes` normalising line endings to LF, and an MIT `LICENSE`.
