# Documentation index - what is in each file

The reference for finding the right document **without opening it**. One line per file: what it contains. Grouped as the research book is - decisions (ADRs), experiment results (STATUS logs), and guides. For the reading order and the current state, see [README](../README.md).

Only files that exist today are listed. The book grows one line at a time, as each piece lands.

## The method - the book (`docs/book/`)

Every formula, decision and guard explained in one continuous document, for a reader who has forgotten all of it. Written under one rule - **every formula cites the module implementing it, every number cites the committed file it came from** - which is how it found a wrong headline, a live `TypeError` and a dozen stale figures. See the [preface](book/00-preface.md) for reading orders.

## Decisions - ADRs (`docs/adr/`)

| ADR | File | The decision |
|-----|------|--------------|
| 001 | [hexagonal-architecture](adr/ADR-001-hexagonal-architecture.md) | Four layers (`contracts`, `ingest`, `research`, `interfaces`) with dependencies pointing inward, and the load-bearing rule that **`research` may never reach for data** - a layer that can quietly re-read the world produces results that cannot be falsified. Records what is deliberately **not** built: no ports package and no storage layer, because an abstract interface earns its place when a second implementation exists and today there is one source feeding one caller. Also fixes two holes in the layering guard (relative imports escaping it, and modules at the package root sitting outside it). |
| 002 | [data-source-and-symbol-set](adr/ADR-002-data-source-and-symbol-set.md) | Dukascopy as the engine's source - fetchable with no API key, extends forward, hashable provenance - with the prior project's exports kept only to reproduce its published baseline once. Verifies instrument identity before adopting it (0.9996 return correlation), drops **VIX** because its short history costs 55% of the sample for a feature correlating -0.011 with the target, and settles the window at 2018-01 onward. Each `(symbol, timeframe)` is fetched independently rather than resampled, because venue anchors move with daylight saving time. |
| 003 | [target-anchored-alignment](adr/ADR-003-target-anchored-alignment.md) | The target's own bars define the timeline and nothing may extend it; auxiliaries are carried forward with their age recorded per symbol. Measured against the original outer-join-and-forward-fill: 24,430 labels against 23,180, 1,288 exact ties against 38, and a class majority that flips - the corrupted data says gold falls 51.47% of the time while the real series says it rises 51.15%. Fixes the identity that each fabricated row adds exactly one tie, and refuses to mix a coarser auxiliary onto a finer target, which would read a bar that has not closed. |
| 004 | [labels-splits-and-baselines](adr/ADR-004-labels-splits-and-baselines.md) | The three decisions hiding inside one line of code each. A label's horizon is a **timestamp**, so 4.37% of bars go unlabelled rather than being answered by a bar fifty hours away; an exact tie is **FLAT**, not a DOWN produced by a strictly-greater comparison; a dead band may not see the move it judges. The split is chronological, purged by the label's reach, and carries **no embargo** - with the reasoning that an earlier draft got wrong recorded as wrong. The majority-class baseline is fitted on **train** and applied blind, because the gap to each block's own majority (2.01 points on validation, 1.06 on test) is larger than the effect being hunted, and accuracy never appears without specificity beside it. |
| 005 | [the-dashboard-runs-the-cli](adr/ADR-005-the-dashboard-runs-the-cli.md) | **Built 2026-08-31.** The Streamlit dashboard invokes `forecast-lab <command> --json` as a subprocess instead of importing `research`, so there is one composition root rather than two implementations that drift; each panel prints the command that produced it, making the page a live demonstration of the reproducibility claim rather than a second copy of it. Read-only commands only - a page a stranger can load should not start a download or rewrite `data/`. Decided in Phase 1 because it makes `--json` a requirement for every command built from here; the coupling it creates - to the CLI's output shape - is named rather than hidden. **Both debts this ADR recorded are now closed (2026-08-30):** `align --json` exists, and `tests/unit/test_cli.py` pins the payload shapes with 46 tests - every command reachable, every payload parseable, and the exit codes distinguished (2 malformed, 1 unanswerable). Deliberately *not* asserted there: the research numbers, which would create a second place to update whenever a measurement moves. **Built and then audited.** Seven pages, each showing the command that produced it, over three modules with one responsibility each: `runner` invokes, `presentation` formats, `dashboard` lays out - and the two that are not Streamlit are testable without it, which is what turned a defect printing four distinct p-values as `0.0000` into a three-line unit test. Four independent reviews returned 21 defects, three of them in guards that did not guard: a payload-contract test that asserted a literal was non-empty, a layering guard scoped by filename that Streamlit's own `pages/` convention walks around, and a read-only guarantee resting on statement order inside two CLI functions. Corrects its own cost estimate (0.8 s claimed, **2.9 s measured, of which 2.8 is interpreter startup**) and records three defects the build found: a subprocess decoding with the parent's cp1252 codec, an unsigned console script blocked by Smart App Control, and `pyarrow` blocked by the same policy, which is why tables are Markdown. |
| 006 | [features-and-stationarity](adr/ADR-006-features-and-stationarity.md) | Indicators are computed on **each symbol's native grid, before any reindexing** - the other order manufactures zero returns on stale rows, and staleness tracks the hour of day, so a model learns a session clock and calls it macro. No column may carry a price level, checked by rebuilding on prices multiplied by ten rather than by trusting a name list. ADF and KPSS are reported and never decide. Records that the original's error was not lacking scale-free features - it computed the distances itself - but keeping the raw levels beside them: twelve of its twenty-three per-symbol columns. |
| 007 | [fitting-models-without-leaking](adr/ADR-007-fitting-models-without-leaking.md) | Every transform fitted on train alone through one `Pipeline`; **selection on validation, test scored once afterwards**; AUC from probabilities rather than hard labels; and no score printed without its baseline on the same line. Measured cost of the alternative: choosing by validation gives -0.21% on test, choosing by test gives +1.85% - **2.06 points that hang entirely on where you look**. Adding two feature columns changed which model wins, without changing any conclusion. Availability is discovered by building each estimator, so a model that cannot run is named rather than silently dropped. |
| 008 | [figures-are-built-in-memory](adr/ADR-008-figures-are-built-in-memory.md) | `research` returns `Figure` objects and never saves one - the layering guard now counts `savefig` as I/O. Four chart types, chosen for what the original's nineteen could not show, since every one of those plots a model against itself. The PNGs are committed while `data/` is not, because they are derived statistics and because a log whose charts live only on the author's machine is not a log. Records that the estimator quarantine caught `sklearn` inside the plotting module and that the right fix was moving the computation, not widening the exception. |
| 009 | [exploratory-analysis](adr/ADR-009-exploratory-analysis.md) | The three ways an EDA goes wrong without anyone noticing, each a correct procedure aimed at a question that already had its answer. Normality is tested on **returns**, with the price kept only for contrast - the price fails for having tails too *short*, which licenses nothing, while returns reach ten standard deviations, which is why a Sharpe's textbook interval is wrong here. A group comparison may not use the variable that defined the groups. And correlations are reported on levels **and** returns together: eight tenths of the original's +0.923 gold-S&P figure is shared trend, and two pairs change sign between the two bases. Replicated across both datasets, where every returns correlation holds and two level correlations flip. |
| 010 | [costs-are-measured-not-assumed](adr/ADR-010-costs-are-measured-not-assumed.md) | The break-even is computed from the venue's own quoted spread rather than carried from a planning assumption. Measured over 51,147 bars: a median round trip of **1.86 bps** against a 13.35 bps average move gives **53.49%**, not the 51.92% this project had quoted sixteen times - the median cost is **14% of the average move** a correct prediction earns. Against the measured figure the selected model falls short by 2.41 points rather than 0.83, so the conclusion firms up rather than shifting. Names the escape route it does not close: a lower-frequency strategy pays proportionally less and faces a much lower bar. |
| 011 | [power-before-verdict](adr/ADR-011-power-before-verdict.md) | A negative result is only a finding if the design could have seen the effect - the calculation the original never ran, and which **reversed this project's own argument**. Against the assumed 1 bp cost a single split genuinely could not resolve the effect; against [ADR-010](adr/ADR-010-costs-are-measured-not-assumed.md)'s measured 3.49 points it resolves it at 99-100% power, turning *"we could not see"* into *"we looked with power to spare"*. Models are scored across five expanding walk-forward folds - **pooled by row count, never averaged**, because folds share training data and their spread is not a sampling distribution - with the constant predictor **refitted inside each fold**, which is what exposed the trap: every edge turns positive not because accuracy rises (it falls 0.21 points) but because the baseline falls 0.67. Reports the nominally significant +0.97% and then discounts it in three stated steps. Names what stays optimistic: overlapping windows make bars dependent, so 100% power must not be read literally. |
| 012 | [turnover-and-dependence-are-measured](adr/ADR-012-turnover-and-dependence-are-measured.md) | The last two parameters this project assumed while telling everyone else not to - one flattering the conclusion, one undermining it. **Turnover**: ADR-010 asserted that every model here flips position half the time; measured it is **17.6% to 38.4%** and predictions autocorrelate at +0.22 to +0.61, so every published break-even was quoted at a frequency none of them trades at. The best case goes from *short by 2.26 points* to **short by 0.46**, and the ordering inverts - by accuracy HistGradientBoosting wins, by whether it pays for itself Naive Bayes is closest, because it holds 5.7 bars. **Dependence**: ADR-011's caveat that overlapping windows inflate every standard error is measured at **0.97** - the features autocorrelate at +0.93 and +0.99 but model correctness at -0.020, because a near-coin-flip outcome inherits almost none of the dependence of its inputs. Records why `arch` is used and deliberately **not** quarantined: the three existing quarantines exist for untyped libraries and `arch` ships `py.typed`. |
| 013 | [skill-and-profit-are-separate-questions](adr/ADR-013-skill-and-profit-are-separate-questions.md) | The project's answer, which needed two questions kept apart. **Skill**: Pesaran-Timmermann against *independence* rather than a coin flip - because a predictor that always says UP on a series rising 52% of the time scores 52% and knows nothing - corrected with Holm across eighteen tests. **9 of 18 survive**, the best at z = 4.61. **Profit**: strategy returns net of the venue's spread, benchmarked against holding the asset rather than against zero. **0 of 18 make money** under either position framing; Hansen SPA p = 0.761, Romano-Wolf StepM rejects nothing, Deflated Sharpe 2.3e-10. The finding is the gap: the models turn buy-and-hold's +100.9% into -86.9%. Records the `arch` asymmetry that reported a superior model as the label `'4'`, and why a battery is only credible if each test is also shown an effect that is real. |

ADX moved by 7.1e-03 on a dimensionless quantity - but across **134 consecutive rows out of 23,181**, the signature of a Wilder recursion carrying one flipped tie forward, with the 99th percentile at 7.0e-10. Also: ADX shares ATR's warm-up-of-zeros defect, so it is the recursion family rather than one function. Sidecar: [features-policy.json](status/features-policy.json). |
| [2026-08-24 - Models](status/STATUS-2026-08-models.md) | The honest pipeline selects **LightGBM** - the same model the original selected - and on test it loses to a constant predictor by **0.64 points**, where the original reported the same model losing by 0.33. Puts numbers on the multiplicity argument: 18 configurations, the expected maximum under the null is +1.59%, the best observed is +2.00% (z = 2.30, short of Holm's 2.77), and only **5 of 18** have a positive edge where a coin would give 9. Corrects ADR-006 on PCA: with every price level removed, 17 features still collapse to 6 components. Run on both datasets: the selected model loses by 0.21 points on the reference data and wins by 0.15 on the canonical - **the sign flips and both sit far inside the noise**, while no configuration of eighteen clears break-even on the larger sample. Sidecars: [model-comparison.json](status/model-comparison.json) and [model-comparison-canonical.json](status/model-comparison-canonical.json). |
| [figures/](status/figures/) | Eight committed charts, regenerated by `train --figures`. The one to look at first is `edge-test.png`: every configuration against the constant predictor and the break-even line, with thirteen of eighteen below the first and one above the second. |
| [2026-08-27 - Exploratory analysis](status/STATUS-2026-08-exploratory.md) | Three of the original's EDA findings dissolve and one reverses. The gold-S&P correlation of **+0.923** is **+0.13** on returns; its normality test was aimed at the price rather than at returns; and its t-test compared the very variable that defined the groups, so it could not have failed. The replication across two venues is the strongest part: every returns correlation holds while **DXY and WTIUSD change sign on levels** purely from extending the window. Also: the share of rising bars drifts three points across nine years, which is the argument for walk-forward stated without reference to any model. Sidecars: [eda-summary.json](status/eda-summary.json), [eda-summary-canonical.json](status/eda-summary-canonical.json). |
| [2026-08-27 - Walk-forward](status/STATUS-2026-08-walk-forward.md) | The firmest test this project can run: six models scored over **40,587 bars** across five expanding folds spanning 2019-06 to 2026-08. The best reaches **51.23%** against a **53.49%** break-even - short by **2.26 points** - while the design resolves **0.62%** and would detect a profitable edge essentially every time, which makes the negative result a finding rather than a failure to look. All six edges turn positive, and section 4 shows why that is an artefact: **the baseline falls further than the accuracy does**. The +0.97% best edge is 3.91 sigma and survives Holm across six models; it is still a quarter of what costs demand. Sidecar: [walk-forward-canonical.json](status/walk-forward-canonical.json). |
| [2026-08-28 - Turnover and dependence](status/STATUS-2026-08-turnover.md) | The two assumed parameters, measured, in opposite directions. Turnover was 0.5 by assumption and **17.6%-38.4%** by measurement, which drops the closest model's shortfall from 2.26 points to **0.46 (1.86 sigma)** and inverts the ranking. Serial dependence was asserted to inflate every standard error and measures **0.97x**, so `0.5/sqrt(n)` was already honest. Carries the sensitivity that makes the thin rejection firm - at the mean spread 2.56 sigma, at the 95th percentile 6.46 - and the synthetic AR(1) check (3.64x) that makes the null credible. Sidecar: [walk-forward-canonical.json](status/walk-forward-canonical.json). |
| [2026-08-30 - The verdict](status/STATUS-2026-08-verdict.md) | **A real edge, worth less than nothing.** Nine of eighteen configurations survive Holm on Pesaran-Timmermann (best z = 4.61, p < 0.00001), so the directional signal is not an artefact of searching. Zero of eighteen make money: the best loses **86.9%** over the scored period while holding gold returns **+100.9%**, and the friendlier long-or-flat framing does not change the count. Carries the reason the null is credible - each test shown an effect that is real - and the two defects the run found in its own code. Sidecar: [verdict-canonical.json](status/verdict-canonical.json). |
| [2026-09-02 - The rebuild against the notebooks](status/STATUS-2026-09-parity.md) | **The audit this repository owed itself.** Both notebooks read cell by cell against the rebuild. The counts check out - 23 indicators in the original, 19 here by an explicit policy, and the notebook miscounts its own at 27. But five published claims do not: the two row counts were blamed on crypto when the cause is a `dropna()` inside a loop paying a 199-row warm-up ten times (24,431 - 10x199 = 22,441, exactly); *"the maximum of thirty draws"* belongs to the other notebook, which ran 12; and **the triumphalist quote this project argues against is from the accompanying report, not the notebook** - whose own final cell says the model does *not* reach usable performance and that an AUC near 0.5 is consistent with efficient markets. Also lists four contradictions inside the original that we never reported, and ten analyses with no counterpart here. |
| [2026-09-02 - WHOLE against FOCUS](status/STATUS-2026-09-whole-vs-focus.md) | **The question the original asked and could not answer.** Its two modes ran over 24,232 and 22,441 rows, so the comparison mixed a change of feature set with a change of sample; this repository built both on a shared index and then never ran a model in WHOLE. Matched on folds, bars and design - 36,567 scored bars and a 0.65% detection floor on both sides, with only the feature count differing, 19 against 179 - **FOCUS wins on five of six estimators**. Positive edges fall from 4 of 6 to 1 of 6 and the best from **+0.67% to +0.16%**. Nothing pays for itself in either mode, so the verdict is untouched. Names the reading it cannot separate: whether the extra markets carry no signal, or carry signal that being forward-filled destroys. |
